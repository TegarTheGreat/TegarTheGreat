I build things at the intersection of **AI and product** — autonomous agents, prompt
systems, and tools that turn messy human intent into software that works. Most of what
you'll find here started as a problem I had, and stayed because other people had it too.

- 🧠 Currently deep in **LLM agents, prompt architecture, and AI-assisted workflows**
- 🛠️ Shipping in **TypeScript / Python**, wired up with **Node.js** and **React**
- 🌐 More about my work at **[tegarprayuda.com](https://tegarprayuda.com)**
- 💬 Ask me about prompt engineering, agent design, or shipping side projects solo
- ⚡ Fun fact: the best system prompt is the one you deleted half of
